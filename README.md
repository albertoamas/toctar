# TocTar Detailing

Sitio web y sistema de gestión para TocTar Detailing (Tarija, Bolivia). Desarrollado por YankoSoft.

## Empezar

```bash
cp .env.example .env
docker compose up -d
npm install
npm run almacenamiento:preparar
npm run dev
```

La app queda en http://localhost:3000. Contexto, comandos y convenciones en `CLAUDE.md`; documentación del proyecto en `docs/`.
